# 📞 Call Center Performance Dashboard (Excel Project)

## 📊 Project Overview
This project presents an interactive **Call Center Performance Dashboard** built using Microsoft Excel.

The dashboard analyzes call center operations data to monitor KPIs, evaluate agent performance, and identify trends that impact customer service quality and operational efficiency.

It transforms raw call logs into actionable insights for performance improvement and strategic decision-making.

---

## 🎯 Business Objectives
This dashboard helps stakeholders:

- Monitor overall call volume and trends
- Track agent performance metrics
- Analyze call resolution performance
- Measure customer satisfaction indicators
- Identify peak hours and workload distribution
- Improve operational efficiency

---

## 🛠 Tools & Technologies Used
- **Microsoft Excel**
  - Pivot Tables
  - Pivot Charts
  - Slicers
  - Conditional Formatting
  - Advanced Formulas
  - KPI Cards
  - Data Cleaning & Transformation

---

## 📈 Key KPIs & Metrics
- Total Calls
- Answered vs Unanswered Calls
- Average Handling Time (AHT)
- Call Resolution Rate
- Agent Performance Comparison
- Call Distribution by Time/Day
- Customer Satisfaction Indicators (if included)
